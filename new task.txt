17. XKIRO CONFIGURATION
=======================

Sử dụng xKiro OpenAI-compatible API.

Base URL:

https://api.xkiro.com/v1

Environment variable:

XKIRO_API_KEY

Tạo hoặc kiểm tra:

.env.local

Nội dung:

XKIRO_API_KEY=YOUR_XKIRO_API_KEY

Tạo:

.env.example

với:

XKIRO_API_KEY=

QUAN TRỌNG:

API key chỉ được dùng server-side.

Frontend KHÔNG được truy cập:

process.env.XKIRO_API_KEY

Không đưa API key vào:

localStorage
sessionStorage
client state
URL
query params
frontend bundle
logs

Frontend chỉ gọi API nội bộ.

==================================================
18. XKIRO API CLIENT
====================

Tạo một abstraction riêng:

lib/xkiro/client.ts

hoặc architecture tương đương.

Client phải:

* đọc XKIRO_API_KEY
* sử dụng baseURL https://api.xkiro.com/v1
* gọi OpenAI-compatible endpoint
* hỗ trợ streaming nếu API hỗ trợ
* xử lý errors
* timeout
* model unavailable
* rate limit

Không duplicate API logic ở nhiều component.

20. VERCEL DEPLOYMENT
=====================

Làm project tương thích Vercel.

Kiểm tra:

npm run build

Nếu build lỗi:

TỰ SỬA.

Không dừng ở việc báo lỗi.

Sau đó hướng dẫn rõ cách deploy.

README phải có:

LOCAL SETUP

1. Clone project
2. npm install
3. tạo .env.local
4. thêm:

XKIRO_API_KEY=your_key

5. npm run dev

VERCEL SETUP

1. Push project lên GitHub.
2. Import repository vào Vercel.
3. Vào:

Project Settings
→ Environment Variables

4. Tạo:

Name:
XKIRO_API_KEY

Value:
API key xKiro của user

5. Chọn:
   Production
   Preview
   Development

nếu phù hợp.

6. Save.
7. Redeploy.

Sau deploy:

mở website
→ Settings
→ Test Connection
